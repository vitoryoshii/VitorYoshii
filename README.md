## Sobre mim

Sou **desenvolvedor de software** e **fundador da [VyteTech](https://vytetech.com)**. Atuo na construção de soluções digitais, conectando engenharia de software, visão de produto e necessidades reais de negócio.

Tenho interesse especial em **backend, APIs, sistemas web, integrações, automações e arquitetura de software**. Gosto de entender o problema antes de escolher a tecnologia — e de construir soluções que sejam claras, sustentáveis e possíveis de evoluir.

- **Engenharia:** desenvolvimento de aplicações, APIs REST, persistência de dados e testes.
- **Produto:** transformação de requisitos em experiências e fluxos funcionais.
- **Negócio:** soluções digitais que reduzem trabalho manual e apoiam operações.

## Projetos em destaque

### [Conecta Comunidade](https://github.com/vitoryoshii/conecta-comunidade)

Plataforma comunitária que aproxima pessoas que precisam de ajuda, doadores, voluntários e instituições. Inclui interface Web/PWA, aplicativo Android em homologação e API separada.

**Stack:** Python · Flet · FastAPI · SQLModel · PostgreSQL  
**Links:** [Repositório](https://github.com/vitoryoshii/conecta-comunidade) · [Acessar a Web/PWA](https://conecta-comunidade-web.vercel.app)

### [WorkoutAPI](https://github.com/vitoryoshii/workoutapi-bootcamp-dio)

API RESTful para gerenciamento de atletas, categorias e centros de treinamento, com foco em modelagem de dados e operações assíncronas.

**Stack:** Python · FastAPI · SQLAlchemy Async · Pydantic  
**Link:** [Ver código](https://github.com/vitoryoshii/workoutapi-bootcamp-dio)

### [Portfólio Pessoal](https://github.com/vitoryoshii/my-page-portifolio)

Aplicação web para apresentar projetos e trajetória profissional, com interface responsiva e arquitetura SPA.

**Stack:** React · TypeScript · Vite · Tailwind CSS  
**Link:** [Ver código](https://github.com/vitoryoshii/my-page-portifolio)
